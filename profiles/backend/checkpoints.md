## Backend checkpoints (in addition to 1–22)
- **B1. API contract details**: success envelope and error body shape exactly as the contract (e.g. a flat error with `code`,
  `message`, `details?`, `retryAfterSeconds?`, `correlationId`); 401 only for an unusable token, while business refusals are
  400/403/409 with a `code`; premium/plan refusals are 403 with their own code; every 429 carries `Retry-After` (+ a body field if
  the contract says so).
- **B2. Pagination**: keyset/cursor only (opaque, versioned cursor; `nextCursor` null when exhausted); no OFFSET/Skip; no
  `hasMore` unless the contract has it; page size bounded.
- **B3. Idempotency**: the mode per endpoint (stored / natural / domain); a replay returns the identical status + body; keys are
  scoped per (owner, operation).
- **B4. Ownership**: identity comes from the token subject, never the body. Every owner-scoped query, update, delete and bulk
  statement filters by the owner FIRST, including lookups by an entity id (ids may repeat across owners after import/export).
- **B5. Data layer**: schema conventions (naming, precision); an index for every new query (WHERE + ORDER covered; owner column
  first in composite indexes); explicit FK delete behaviour; concurrency tokens where needed; migrations generated by the
  framework tool and read in full; the model-consistency check green; transactions short with no external I/O inside.
- **B6. Background work**: jobs idempotent, batched and bounded per run; in-process queues bounded with an explicit
  back-pressure/drop policy; no fire-and-forget tasks.
- **B7. Startup and options**: settings classes validated at startup; required env keys present in every example env file;
  no service locator; dependency lifetimes correct (no scoped dependency captured by a singleton).
- **B8. Live API evidence**: containers up and healthy; the e2e suites of changed endpoints pass with their own check counts;
  each new or changed endpoint is called (e.g. curl), with request + response pasted and compared with the contract.
